# Tasply

**Plan less. Finish the day. Grow a forest.**

Tasply is an Android day planner for people who struggle with judging how much fits
in one day. Plan tasks with time estimates, track how long they really take, and
grow a forest with every finished task.

This repository is the public home of Tasply: bug reports, feature ideas and the
privacy policy. The app's source code is not published here.

## Report a bug or suggest an idea

1. Go to [Issues](https://github.com/leafline-studio-apps/tasply/issues).
2. Search first. Someone may have reported the same thing already.
3. Click **New issue** and pick **Bug report** or **Feature idea**.

Issues are public, so please don't include personal information (email, phone number,
private task names) in your report.

Prefer email? Write to [leafline.studio.apps@gmail.com](mailto:leafline.studio.apps@gmail.com).

## Privacy

Tasply has no account, no ads and no tracking. All your data stays on your phone.
Read the full [privacy policy](https://leafline-studio-apps.github.io/tasply/privacy-policy.html).
